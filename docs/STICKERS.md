# 给推送配一张表情包（可选）

文字是信息，表情是情绪。一个只有文字的通知，看十遍以后你就分不清"完成了"和
"又失败了"，得读进脑子里才知道。配张图，一眼就够。

这个功能**不是必须的**，默认关。它的实现不在这个包里——挑图和发送都在接收端
（比如自己的 Hermes 网关）做，插件只负责把事件说清楚。这样插件保持零依赖、
零素材、可以公开分发，素材的版权也不会跟着代码跑出去。

## 素材：大肥鱼（强烈安利）

![大肥鱼示例](https://kiriyuki.com/showcase?p=%E5%A4%A7%E8%82%A5%E9%B1%BC)

- **作者**：B 站 [可以叫我云大人](https://space.bilibili.com/103739)
- **制作**：[@kiriyuki.com](https://kiriyuki.com) · [整包展示页](https://kiriyuki.com/showcase?p=%E5%A4%A7%E8%82%A5%E9%B1%BC)
- **规模**：322 张动图，25 个情绪分类（开心/疑惑/无语/垮掉/嘲讽/安慰……）
- **许可**：CC-BY-NC-4.0 —— 非商用，署名保留

我拿来配事件是这样（`sticker_map`，事件名 → 素材 id 片段）：

| 事件 | 素材 | 为什么是这张 |
|---|---|---|
| `task_done` | `11N08_拉炮` | 拉了炮，庆祝成功 |
| `task_failed` | `6N10_碎了` | 受打击后整个人碎掉 |
| `task_blocked` | `11N06_小问号` | 满头问号，卡住了 |
| `task_truncated` | `12N09_擦手机` | 看不下去，擦擦屏幕 |
| `task_aborted` | `6N11_嫌弃` | 嫌弃地看一眼转身走掉 |
| `waiting_approval` | `10N01_猫猫搓手` | 搓手等好消息 |
| `waiting_input` | `6N02_猫在么` | 探头问"在吗" |
| `plugin_mounted` | `9N07_蹦` | 冒泡报到 |
| `plugin_error` | `12N10_爆爆猫` | 绷不住了 |

选图的诀窍是**别选"正确"的，选"有反应"的**。`task_done` 配一个打勾图标是
正确但无聊的；配一张拉炮，你会想笑一下。通知里那点人情味就来自这一下。

## 谁提供图，图放哪

素材由使用者自己准备和安装，仓库里不带任何图片：插件只管把事件说清楚，
图挂在接收端。素材许可各归各作者（这套是 CC-BY-NC-4.0），分发时保留作者与许可证即可。
